# ميزان (Mizan) — Clickable Front-End Demo

A click-through React prototype of 4 locked design screens for a legal practice
platform. Front-end demo only — no backend, no auth, no database. All content
is hardcoded Arabic mock data, RTL, Almarai font.

Live demo: https://khaledgamal258.github.io/mizan-demo/

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploys automatically to GitHub Pages on push to `main` via GitHub Actions.
